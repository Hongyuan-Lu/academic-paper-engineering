# 幻灯片处理代理

将 PPT 幻灯片作为科研论文外部资产进行处理。

## 定位

PPT 不是直接转换为 LaTeX，而是作为科研论文外部资产来源。

## 处理流程

```
PPT 文件 (.pptx)
  ↓
幻灯片解析
  ↓
识别图表/图片/文字
  ↓
Figure/Table/Paragraph IR
  ↓
进入论文
```

## 解析能力

使用 `scripts/pptx/` 中的脚本解析 PPT 文件：

- 提取每页幻灯片的文本内容
- 提取幻灯片中的图片
- 提取幻灯片中的图表数据
- 提取幻灯片中的表格

## 资产提取

### 图片提取

- 提取幻灯片中的嵌入图片
- 识别图片在幻灯片中的位置和上下文
- 尝试匹配图片与标题文字

### 表格提取

- 提取幻灯片中的表格数据
- 识别表格的行列结构
- 提取表格标题或描述

### 图表提取

- 提取幻灯片中的图表（柱状图、折线图、饼图等）
- 尝试提取图表的原始数据
- 识别图表的标题和坐标轴标签

### 文本提取

- 提取幻灯片的标题和正文
- 识别要点列表
- 按逻辑顺序组织文本

## 输出格式

```json
{
  "source_file": "实验汇报.pptx",
  "slides": [
    {
      "slide_number": 1,
      "title": "实验结果",
      "assets": [
        {
          "type": "figure",
          "source": "slide1_image1.png",
          "description": "...",
          "suggested_caption": "..."
        },
        {
          "type": "table",
          "data": {
            "headers": [],
            "rows": []
          },
          "suggested_caption": "..."
        }
      ],
      "text_content": "..."
    }
  ]
}
```

## 注意事项

- PPT 中的图片可能质量较低，需要评估是否适合用于论文
- PPT 中的表格可能格式不规范，需要结构化验证
- PPT 中的图表可能无法提取原始数据，需要报告
- 保持幻灯片之间的逻辑顺序
