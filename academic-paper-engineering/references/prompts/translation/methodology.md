# 方法论翻译规则

翻译论文方法论部分。

## 核心要求

- 技术术语精确翻译
- 数学公式保持不变
- 算法步骤清晰准确
- 实验设置完整保留

## 翻译要点

- 模型/方法名称不翻译，保持原文
- 变量符号不翻译
- 数据集名称保持原文
- 评价指标名称保持原文或使用标准翻译
- 硬件/软件名称保持原文

## 常用表达

- "本文提出" -> "We propose" / "This paper proposes"
- "实验环境" -> "experimental setup" / "experimental environment"
- "数据集" -> "dataset"
- "评价指标" -> "evaluation metrics" / "metrics"
- "超参数" -> "hyperparameters"
- "训练" -> "training"
- "验证" -> "validation"
- "测试" -> "testing"
- "损失函数" -> "loss function"
- "优化器" -> "optimizer"
- "学习率" -> "learning rate"
- "批大小" -> "batch size"
- "迭代次数" -> "number of iterations" / "epochs"

## 公式处理

- 公式编号保持一致
- 公式中的文字说明需翻译
- 公式后的解释文字需翻译
- 变量定义需翻译但变量符号不变
