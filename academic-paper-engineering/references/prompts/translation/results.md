# 结果翻译规则

翻译论文实验结果部分。

## 核心要求

- 所有数值必须与原文完全一致
- 所有单位必须保持原始格式
- 统计指标精确翻译
- 实验结果的描述保持客观

## 翻译要点

- 表格和图片的标题说明（caption）需翻译
- 表格中的文字内容需翻译
- 表格中的数值不翻译
- 图片中的标注文字视情况翻译

## 常用表达

- "如表1所示" -> "As shown in Table 1"
- "如图2所示" -> "As illustrated in Figure 2"
- "结果表明" -> "The results show that" / "The results indicate that"
- "可以观察到" -> "It can be observed that"
- "优于" -> "outperforms" / "is superior to"
- "提升了" -> "improved by" / "increased by"
- "降低了" -> "decreased by" / "reduced by"
- "达到了" -> "achieved" / "reached"
- "平均" -> "on average" / "average"
- "最高" -> "the highest" / "the best"
- "对比" -> "compared with" / "in comparison with"

## 数值处理

- 百分比保持原始格式
- 小数位数保持一致
- 科学计数法保持原始格式
- 置信区间和误差范围精确保持
