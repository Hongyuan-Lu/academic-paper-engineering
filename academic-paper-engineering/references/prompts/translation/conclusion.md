# 结论翻译规则

翻译论文结论部分。

## 核心要求

- 准确总结研究贡献
- 不添加正文未讨论的内容
- 保持简洁有力
- 与摘要和引言保持一致

## 结构理解

结论通常包含：

1. 研究工作总结
2. 主要发现和贡献
3. 研究意义
4. 未来工作展望

## 翻译要点

- "本文" -> "In this paper, we" / "This paper"
- "提出了" -> "proposed" / "presented"
- "实现了" -> "achieved" / "implemented"
- "实验验证了" -> "Experimental results verified" / "Experiments demonstrated"
- "未来工作" -> "In future work" / "Future work includes"
- "总之" -> "In conclusion" / "In summary"

## 注意事项

- 结论中的数值必须与结果部分一致
- 不引入新的引用
- 不引入新的图表
- 保持与全文一致的术语
