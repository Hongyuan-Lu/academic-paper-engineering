# 讨论翻译规则

翻译论文讨论部分。

## 结构理解

讨论部分通常包含：

1. 主要发现的总结
2. 与已有研究的比较
3. 结果的解释和分析
4. 研究 limitations
5. 未来工作方向

## 翻译要求

- 保持论证逻辑的完整性
- 正确处理推测性和确定性表述
- 保持与结果部分的一致性
- 不添加原文没有的讨论内容

## 常用表达

- "这表明" -> "This suggests that" / "This indicates that"
- "可能的原因是" -> "A possible reason is that"
- "这与...一致" -> "This is consistent with"
- "这与...不同" -> "This differs from" / "In contrast to"
- "值得注意的是" -> "It is worth noting that"
- "我们的研究存在一些局限性" -> "Our study has several limitations"
- "未来工作" -> "future work"
- "进一步研究" -> "further research" / "further investigation"

## 注意事项

- 区分事实陈述和推测
- 保持适度的学术谨慎
- 不夸大研究结果
- 不贬低他人工作
