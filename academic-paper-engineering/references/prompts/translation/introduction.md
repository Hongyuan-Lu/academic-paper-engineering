# 引言翻译规则

翻译论文引言部分。

## 结构理解

引言通常包含：

1. 研究领域的背景介绍
2. 现有研究的回顾
3. 研究空白或问题识别
4. 本文的研究目的和贡献
5. 论文组织结构

## 翻译要求

- 从宏观到微观的逻辑递进
- 正确处理文献引用，保持引用格式
- 区分作者自己 work 和他人 work 的表述
- 使用适当的时态：
  - 一般事实用现在时
  - 已有研究用过去时或现在完成时
  - 本文工作用过去时或现在时（视期刊风格）

## 特殊处理

- "本文" -> "this paper" / "this study" / "we"
- "近年来" -> "in recent years"
- "目前" -> "currently" / "to date"
- "然而" -> "however" / "nevertheless"
- "因此" -> "therefore" / "thus" / "consequently"
- "据我们所知" -> "to the best of our knowledge"
