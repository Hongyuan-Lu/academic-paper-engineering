# 文献综述翻译规则

翻译论文文献综述部分。

## 核心要求

- 准确传达每篇被引文献的研究内容和结论
- 保持引用格式完全一致
- 不编造未被引用的文献
- 保持作者对文献的评价和比较

## 翻译要点

- 区分"Smith et al. 提出了..."和"Smith et al. (2020) 提出了..."
- 正确处理多个文献的并列引用
- 保持时态一致：
  - 描述他人方法用过去时
  - 描述普遍认知用现在时
- 学术表达：
  - "提出了" -> "proposed" / "introduced" / "presented"
  - "解决了" -> "addressed" / "solved" / "tackled"
  - "证明了" -> "demonstrated" / "proved" / "showed"
  - "指出了" -> "pointed out" / "indicated" / "noted"
  - "总结了" -> "summarized" / "reviewed" / "surveyed"

## 注意事项

- 不遗漏任何被引文献
- 不改变引用的顺序
- 保持对比和批评的语气
- 不添加主观评价
