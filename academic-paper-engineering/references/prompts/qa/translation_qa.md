# 翻译质量检查

对翻译结果进行质量检查。

## 检查项

### 1. 术语一致性

- 检查技术术语翻译是否一致
- 对照术语词典验证
- 标记不一致的术语翻译

### 2. 数字准确性

- 所有数字必须与原文完全一致
- 检查百分比、小数、科学计数法
- 检查统计指标（p值、F值、置信区间等）

### 3. 公式完整性

- 所有公式必须与原文一致
- 检查变量符号
- 检查公式编号

### 4. 引用正确性

- 所有引用必须与原文一致
- 检查引用格式
- 检查引用顺序

### 5. 结构保持

- 章节结构必须与原文一致
- 段落顺序必须保持
- 列表结构必须保持

### 6. 语言质量

- 语法正确性
- 学术风格一致性
- 时态使用正确性
- 被动/主动语态适当性

## 质量阈值

| 检查项 | 阈值 |
|---|---|
| 术语准确率 | >= 95% |
| 数字准确率 | 100% |
| 引用准确率 | 100% |
| 结构保持率 | >= 98% |
